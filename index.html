BOOK EXPLORER: Discover Your Favourite Author

Learning objective: write a Python program that uses input(), print(), variables, functions and if/else to find a book’s author.

📖🐍🔎

⏱ 25-minute plan

TimeActivity
5 minMeet the project and read the program
5 minType the code; find the variables and input
10 minRun it, test a book title, fix bugs
5 minImprove the output and demonstrate

🪜 Steps

  1. Open IDLE, Thonny or an online Python editor.
  2. Copy the code (button below) and paste it into a new file.
  3. Save it as book_explorer.py and press Run (F5).
  4. Type a book title, e.g. Alice’s Adventures in Wonderland.
  5. Test three different books and a made-up title.

Uses the free Open Library service: no account or API key needed. If the internet fails, the program switches to clearly labelled SAMPLE demo data. (Gemini would need a private API key kept in an environment variable, never typed into shared code.)
